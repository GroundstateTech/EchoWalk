# Project Governance

EchoWalk is an open-source Groundstate Technology LLC research project. Source code is licensed under the repository license so the community can use, study, modify, fork, and redistribute it under those terms.

## Official project stewardship

The official EchoWalk repository is stewarded by Groundstate Technology LLC and designated maintainers. Open-source licensing does not require the official project to accept every proposed change. Maintainers may review, request changes, merge, defer, or decline contributions based on project scope, accessibility, safety, maintainability, compatibility, licensing, test quality, and long-term direction.

## Ownership and licensing

Groundstate Technology LLC retains ownership of Groundstate-created code, documentation, project branding, and other Company-created material, subject to the rights granted by the applicable open-source licenses. Contributors retain copyright in their contributions unless a separate written assignment applies.

Submitting a contribution does not create employment, partnership, membership interests, equity, royalties, or other ownership in Groundstate Technology LLC.

## Accessibility and safety

EchoWalk is experimental accessibility research software. Contributions must not represent the project as a certified mobility aid, medical device, or substitute for established orientation-and-mobility tools unless an appropriate validation and regulatory basis exists.

Changes affecting acoustic ranging, obstacle warnings, haptics, permissions, calibration, or other safety-relevant behavior should include reproducible testing and clearly state known limitations.

## Community participation

Issues, pull requests, testing, documentation, device test reports, accessibility feedback, design proposals, and security reports are welcome. Technical disagreements should be resolved through evidence, reproducible tests, project goals, and respectful discussion.

## Forks and branding

Forking is permitted under the repository license. Materially modified distributions should use distinct branding and must not falsely represent themselves as official Groundstate or EchoWalk releases. See `BRAND_POLICY.md`.

## Stewardship objective

The maintainer's role is to keep the official project coherent, safe, buildable, documented, and faithful to its accessibility-research purpose while preserving legitimate community freedom under the license.
